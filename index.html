QRScout Updates

Install the latest REBUILT scouting app over Wi-Fi.

Current release: 1.0 · Build 1

Update an iPad

Open this page in Safari on the jailbroken iPad, then use the button below.

Install / Update QRScout
  1. Tap Install / Update QRScout.
  2. Choose Install when iOS asks for confirmation.
  3. Return to the Home Screen and wait for the app to finish installing.
  4. Open QRScout and confirm the updated version works.
Required: unsigned OTA installation needs AppSync Unified on the jailbroken iPad.

Do not open the manifest

manifest.plist is a machine-readable instruction file for iOS. It may open as confusing XML in Xcode or Safari. You do not edit or open it to update an iPad—the red button above sends it to the iOS installer automatically.

Publish a future update

These steps are for the person building a new version on the Mac.

1. Build with a higher version

APP_VERSION=1.1 BUILD_NUMBER=2 \
QRSCOUT_UPDATE_URL=https://amadeusjackson.github.io/QRScout-OTA/manifest.plist \
./scripts/build_legacy.sh

2. Prepare the two upload files

cp build/QRScoutLegacy-unsigned.ipa QRScoutLegacy.ipa

./scripts/make_manifest.sh \
https://amadeusjackson.github.io/QRScout-OTA/QRScoutLegacy.ipa \
manifest.plist 1.1 2

3. Replace two GitHub files

In the AmadeusJackson/QRScout-OTA repository, replace QRScoutLegacy.ipa and manifest.plist. Keep the filenames unchanged, commit the replacements, and wait about one minute for GitHub Pages to deploy.

4. Test one iPad

Return to this page on one iPad and use the red update button. Once it succeeds, update the remaining iPads.
